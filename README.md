## 🛠️ Gateway Architecture

- **Ultra-Fast & Lightweight**: Pure semantic HTML5 + CSS3 glassmorphism, zero external frameworks, and micro-particle background canvas (<15KB total).
- **Multi-Device Responsive**: Edge-to-edge layout with Safari `viewport-fit=cover` and notch-aware paddings.
- **Auto-Pilot Router**: Optional intelligent query-based redirect routing (`?autopilot=1`).
