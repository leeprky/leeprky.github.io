## 🛠️ Architecture & Design System

- **Blueprint Engineering Theme**: Shared design system with ISO frame zones, technical typography (Space Grotesk + JetBrains Mono), satin ridges background canvas, and title block.
- **Dedicated Repositories**: Portfolio and Drunk Uno run independently in their own dedicated repositories with independent releases.
- **Zero Friction Forwarding**: Direct links and legacy paths preserve query strings (e.g. `?room=XYZ`) so existing links and bookmarks never break.
